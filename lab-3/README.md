# Lab 3: Binary Classification for Ticket Escalation

This repository contains the completed Jupyter Notebook for Lab 3.

## Files
- `Lab3_Ticket_Escalation_Classification.ipynb` — completed notebook with executed outputs.
- `classification_escalation.csv` — dataset used by the notebook.

## Run
1. Clone or download this repository.
2. Install dependencies:
   ```bash
   pip install numpy pandas matplotlib scikit-learn jupyter
   ```
3. Start Jupyter:
   ```bash
   jupyter notebook
   ```
4. Open `Lab3_Ticket_Escalation_Classification.ipynb`.

The notebook follows the lab instructions for data inspection, preprocessing, model comparison, threshold evaluation, cost analysis, and stratified 5-fold KNN tuning.
